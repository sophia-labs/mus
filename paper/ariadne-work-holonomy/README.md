## Central result

At control configuration `lambda`, the acoustic system has a state fiber
`H_lambda` and positive energy metric `M_lambda`.  A configuration change is an
explicit state transport `T`.  In energy-normalized coordinates,

```text
A = M_1^(1/2) T M_0^(-1/2) = U H
```

is the right polar decomposition.  The positive factor `H` determines exact,
state-dependent control work,

```text
W_ctrl = 1/2 z^T (H^2 - I) z,
```

while `U` is metric-compatible transport.  Ordered products of `U` can retain
closed-path state memory.  Locally work and transport separate; globally their
interleaving is order-dependent.

The instrument, body, and surrounding space are one graph.  Short cycles form
strings, intermediate resonances form the body, and long cycles form the room
halo.  Room dimensions, boundary properties, loss, dispersion, directionality,
and return coupling are coordinates of the same time-varying control state as
string length, tension, body geometry, and bridge coupling.  Space is not a
post-processing reverb in the proposed system.

## Exact three-mode result

For

```text
C(a,b) = R01(a) R12(b) R01(-a) R12(-b),
x = sin(a/2)^2,
y = sin(b/2)^2,
```

the symbolic derivation gives

```text
trace(C) = (4xy - 3)(4xy - 1)
delta^2 = 16xy(1 - xy)
sin(phi/2)^2 = 4xy(1 - xy)
delta = 2 sin(phi/2)
```

where `delta` is the operator-norm order defect and `phi` is the principal
rotation angle of the closed commutator.  A balanced target loop has the exact
inverse design law

```text
a = b = 2 asin(sqrt(sin(phi/4))).
```

The derivation is recorded in `EXACT-RESULTS.md` and can be regenerated by
`derive_symbolic.py` in the full reproducibility packet.

## Evidence status

The paper distinguishes four evidence classes:

1. measurements from the production Rust Ariadne/Weave branch;
2. analytic identities and proofs in the manuscript;
3. deterministic IEEE-754 float64 reference experiments;
4. pure-core Lean proofs for finite algebraic path laws.

The production variable-delay renderer does **not** yet satisfy the proposed
work-accounted contract.  Its measured upward-fifth bend peaks at 5.38 versus
3.24 unbent, despite lossless explicit Givens scattering.  That 66% transient is
the motivating counterexample, not a result hidden by normalization.

The six-resonator instrument--body--space experiment is a verification
surrogate.  It is not a measured room, a production reverberator, or a listener
study.  It demonstrates the algebraic point that body and space can co-morph in
one coupled state while an energy-neutral transport closes the ledger.

## Lean check

The formal package targets Lean 4.31.0 and has no mathlib dependency:

```bash
cd formal
lake build
```

The module proves exact work telescoping under composition, finite-path ledger
closure, zero work for preserving paths, a nontrivial zero-work commutator
witness, and factor-order-dependent work.  It does not yet formalize SPD matrix
square roots, real polar decomposition, floating-point error, or continuous
connection curvature.
